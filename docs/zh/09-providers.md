# 服务分工：本地机器、NovelAI、Midjourney、Civitai、GPT Image

这页回答三件事：什么活交给哪个后端，每个后端花多少钱，以及怎么操作才不会把付费账号搞丢。
本地出图机、两个靠浏览器面板操作的网页、一个付费云端 API、一个经由编码 agent 调用的图像模型，
全都挂在同一个主会话底下。

> **TL;DR**
> - 按活选后端，不按习惯：全年龄的艺术向交给 Midjourney，标签精确的二次元交给 NovelAI V5，
>   排版和硬控制交给 GPT Image，能重复的活都留在本地，Civitai 只在常设预算内用。
> - 数据集、重复采样、稳定性验证，免费的本地机永远优先于付费云端。云端只用来做方向分叉，每个方向一张。
> - 每次付费调用都先报价、记账、能续跑，超限就停（fail closed）。
> - 网页由一个小 subagent 照抄提示词去提交：只交一次，交完汇报，不碰账号。登录归我本人，下载要我点头。
> - 成人向的活如果有，走单独的私有线，不在本页范围内。

## 通用规则

1. **云端轮次按「几张够做出判决」来定，不按预算上限铺满。**
   理由：本地出图是沉没成本，筛选轮的信息增益饱和得很快。2026-09-16 一份提案给某个波次建议
   2000 Buzz 上限，我砍到 500。上限不是目标。
2. **做数据集优先用免费的本地机，不用付费云端。**
   理由：有一次约 420 Buzz 花在 Civitai 上做数据集，而 Box B 能免费出（日期没记）。
3. **先报价，再花钱，再记账。** 每次付费调用跑之前有价格，跑之后有一行账，收尾时对账。
   理由：见下面 257 Buzz 那次。
4. **付费请求超时或结果不明，一律记为 `outcome_unknown`，绝不自动重试。** 先由人到服务商那边核实。
   理由：回执丢了再重试，可能扣两次钱。
5. **凭据只在组装请求时读取，只放进请求头，不出现在 argv、日志、报错文本和数据库里。**
   理由：旧版 Civitai 客户端把 token 放在 argv 里，任何进程列表都看得到，后来换掉了。
6. **新工具加了云端路径，默认给计划、预设或 dry run。** 自动出图要主动打开。
   理由：来自低量决定（2026-09-16）。
7. **登录归我本人。** 碰到登录页、Cloudflare 验证或验证码，agent 停手，由我在面板里自己过。
   谁都不替我填凭据。理由：仓库主人的决定，背后没有单次事故。
8. **下载到磁盘要我同意，按批次，或在我给过的范围内。** 汇报张数、大小和位置。理由：仓库主人的决定，背后没有单次事故。
   唯一免批的范围是我自己项目出的 Midjourney 图（2026-10-19）。
9. **成人向不进这些后端。** 有的话走单独的私有线，有自己的门。
   理由：Midjourney 审核会封号；Civitai 通道在请求层就固定为 SFW。

## 本地机器

1. **先 Box A，Box A 忙就转 Box B。** 路由先算出哪些机器能接这单（底模、LoRA、线路），再扫 Box A。
   忙的标准：队列非空、空闲显存不到 40%、或者不应答。理由：Box A 是我的游戏机，开着游戏会体现在显存上，agent 要让路。
2. **测试图直接排 Box B，不用问；上 Box A 先问。** 理由：2026-09-30 给的授权，范围限 Box B 和测试图。
3. **只走路由，不直接跑它打印出来的引擎命令。** 先 `--probe`（只读，HOLD 时退出码 3），再用同一条命令加 `--run`。
   理由：打印出来的子命令会跳过等空闲、显存租约和结果记录。
4. **Qwen-Image 跑在 sidecar 里，绝不进生产实例。** 它有自己的模型根目录、自定义节点白名单和只监听回环的端口。
   理由：隔离；sidecar 的 venv 继承生产 venv，原地升级生产 venv 会连带改掉 sidecar。

各条线的配方在各自的页面里。两台出图机的 ComfyUI 截至 2026-10-20 都是 0.42.1。

## NovelAI

1. **没点名模型就用 V5 Full，带 `high complexity`。** 质量词和负面词都只带少量。
   理由：2026-09-17 我定的；V5 的质量开关会把画面拉向趋同。
2. **筛选轮走免费档，按像素数判断。** 免费 = 一次一张、像素不超过 1,048,576（任意形状）、步数不超过 28、没有底图。
   理由：2026-09-30 在网站 Generate 按钮上实测，512x768 和 960x1088 都是 0，1088x1024 就收费。
   旧的「三档预设尺寸」口径从那天起作废。img2img 和 Enhance 永远不免费。
3. **付费组合调用前先报 Anlas。** 本地账本每天上限 300 Anlas，别顺手调高。理由：仓库主人的决定，背后没有单次事故。
4. **自定义 User-Agent。** 理由：2026-08-25/27，CDN 用 403/1010 拒掉了 Python 默认签名。
5. **本地留 manifest，API 没有历史记录。** 理由：没有它，一张图出来就查不到来路。
6. **只有一个调用方，HTTP 429 不重试。** 所有调用走同一个客户端，共用队列锁和账本。
   理由：再开一个临时调用方，会和账本、限流抢。
7. **V5 没有图像参考。** 截至 2026-09-02 没有 Vibe Transfer，也没有 Precise Reference
   （2026-08-28 V5 的 encode 调用返回 HTTP 500，没扣费）。需要用图锁身份的活改用 V4.5。之后的状态没复核。
8. **想保住选中的构图，就把草稿放大后做 img2img。** 免费的 832x1216 草稿，LANCZOS 放大到 1280x1856，
   28 步，strength 0.4，noise 0，约 11 秒。理由：同一个 seed 换尺寸就是另一张图（2026-09-23）。这步收费，先报价。

实测过一天出 370 多张，一次 HTTP 402 都没碰到，社区流传的「每天 190 张」偏保守。

## Midjourney

1. **只用网页版，节奏像人。** 每步点一次，不用脚本、不爬取、不用第三方 API，不改账号、套餐和付款，不碰 Turbo。
   理由：防封号；账号本身就是资产。
2. **只画全年龄。审核逐词读，`--no` 里的词也算。** 被拦就换说法，绝不原样重交。
   理由：多次被拦会收到警告甚至封号。2026-10-15 一条写了「bare black trees」的提示词返回 `softban: true`（原因没查实）。
3. **默认 Relax，每条提示词末尾加 `--relax`。** 只有我正等着这张图拍板、且 Relax 排队超过约 2 分钟，
   或者确实值得用某个只有 Fast 才有的功能时，才用 Fast。每月 Fast 额度至少留 5 小时不动，收尾时报用了多少。
   理由：Standard 套餐下 Relax 不限量，Fast 每月约 15 小时。
4. **速度从提交回执里核对，不开设置面板。** 理由：2026-10-15 有 21/21 个任务回读为 relaxed；
   而 2026-10-14 subagent 点设置图标时被自动权限审查拦下。
5. **绝不直接打开任务页地址。** 待在创建页，从页面数据里读任务 id。
   理由：2026-10-13 打开任务页触发了两次 Cloudflare 验证，第二次只能我本人过。
6. **同一天里 Cloudflare 验证越来越频繁，就放慢。** 少刷整页、拉长间隔、少发几个包。理由：浏览器的可疑分在涨。
7. **提交返回 403 是被拦，不是服务器出错。** 等 10 分钟。200 之后才失败的可以重交一次。
   理由：2026-10-14 一个包对着 403 反复重试，烧了 51 次调用。
8. **V8.2 的提示词正文控制在约 1000 字符以内。** 理由：908 和 1018 字符原样通过，1031 和 1043 被悄悄改写、丢词（2026-10-19）。
   Niji 7 在 1043 字符时没改。

## Civitai

1. **每次付费提交前先拿免费的 what-if 报价。** 理由：价格随引擎、尺寸和 LoRA 数变，报价不花钱。
2. **常设预算：单次请求不超过 30 Buzz，每个本地日历日不超过 150 Buzz。** 预算内不再逐张确认。
   超上限、批量探针、视频，仍然先问。理由：2026-09-30 我定的；逐张确认是云端出图慢的主因。
3. **预算在客户端卡，超了就停。** 理由：Civitai 对 API key 没有服务端额度上限，必须在发请求之前拦住。
4. **每存一张图记一行账；每日合计只算本通道、按本地日历日。** 理由：账本是我们唯一能掌控的花费记录。
5. **任何付费运行前先查账本和输出目录，默认带 `--resume`，跑完对账：账本行数 = 渲染文件数 = spec 条数。**
   多出来就是双跑。理由：见下面 257 Buzz 那次。
6. **贴进聊天回复的付费命令，可能已经被跑过。** 要么别贴，要么贴的时候带上 `--resume`，并假设它已经跑了。
   理由：聊天应用会给代码块加 Run 按钮。
7. **记住几个静默丢字段的坑。** Anima 的 checkpoint 要放在 `diffuserModel` 字段，写在 `model` 字段会被悄悄丢掉。
   每次最多 5 个 LoRA，生态要和 checkpoint 一致。云端通道不开放采样器（实际跑 euler/simple）。
   理由：每一条都是付费跑完回读 workflow 才发现的（2026-09）。

见过的价格（用前先报价复核）：一张 832x1216 smoke 图报价和实扣都是 15 Buzz，耗时 33.7 秒（2026-09-30）；
五个 LoRA 叠加 18 Buzz；走 workflow 端点的 SDXL 文生图 4 Buzz；2026-08 的视频报价从每 5 秒 133 Buzz（ltx2）到 1500（wan）。

## GPT Image

1. **经多路复用器里的 Codex worker 调用，绝不在 agent 沙箱里直接跑。** 主会话决定改什么、审图；Codex 负责生成。
   理由：早先从沙箱直接跑 Codex 的写法（2026-06-22 写下）已经作废。实测每张约 3 万到 7 万 Codex token、2 到 4 分钟。
2. **明令它用自带的图像工具，并给一个逃生口令。** 理由：有个 Codex worker 没调图像工具，而是写代码画了一堆多边形色块（2026-06-20 前就记下了）。
3. **只发增量，不发身份。** worker 自己去读规格文件，任务包里只写场景、姿势、视角和修正。生成前让它先打印最终提示词。
   理由：身份只有一个事实源；最常被漏掉的是头发那一行。
4. **局部修改用编辑模式，写明「只改 X，别的全部不变」。** 理由：比重抽漂移小，有一次编辑只换掉了鞋。

## 流程：浏览器面板操作员的任务包

提示词由主会话写，图也由主会话评。小 subagent（默认 Haiku 5.5，涂蒙版或页面异常时用 Sonnet 5.5）只负责提交和读结果。
面板是共用的，所以同一时间只派一个操作员。在后台派。

1. 写任务包：动作（imagine、vary、upscale、edit），每条提示词都带速度后缀，要操作的已有任务（如果有），
   然后最多 3 条提示词，标明「原样提交，按顺序」。
2. 操作员在本轮开头先调整面板尺寸（视口每轮都会复位；窄于约 630 px 网站会切成手机布局）。
3. 每条提示词四次调用：找输入框；点击并输入；单独一次只读脚本调用，确认文字确实落进去了；回车并等 10 秒。
   脚本调用绝不放进批量动作里。
4. 每 45 到 60 秒读一次结果。整个包最多约 25 次工具调用。
5. 碰到登录、验证码或 Cloudflare 页：停下汇报。提交丢了：汇报，不重发。
6. 汇报控制在 150 词内：每条的状态、任务地址、核实过的设置、审核提示原文照录。

## 流程：一次付费 Civitai 出图

1. 在账本里搜这批的 id，数一下输出目录里已有的文件。
2. 拿免费报价。和单次 30 比；再把今天账本合计加上这次报价，和 150 比。
3. 两道上限都没超：带 `--resume` 出图，追加账本行。超了、或者是批量探针、或者是视频：把参数和总价复述一遍，问我。
4. 核对账本行、文件和 spec 条数。对不上就按可能双跑汇报。

## 付费调用前的检查单

- [ ] 本地机能不能免费回答同一个问题？
- [ ] 这个判决需要几张？计划是不是就这个数？
- [ ] 报价拿了、两道上限查了、账本和输出目录搜了？
- [ ] 续跑开关带上了？
- [ ] argv、日志、回复里都没有凭据？
- [ ] 如果之后要下载：这批我同意了吗？

## 真实案例

- **2026-09-05，双跑多花 257 Buzz。** 两条付费探针命令贴进了回复。我点了代码块上的 Run，又在收件箱点了批准，
  agent 随后又跑了一遍。Anima 6 张、Illustrious 13 张各出了两次。规则：先查账本，默认 `--resume`，跑完对数，
  把贴出去的命令当作已经跑过。
- **日期没记，数据集花了约 420 Buzz。** 一批不挂 LoRA 的数据集交给了 Civitai，而 Box B 当时闲着、免费。规则：数据集走本地。
- **2026-10-13，任务页。** 打开 Midjourney 任务地址招来两次 Cloudflare 验证。规则：待在创建页。
- **日期没记，失控的任务包。** 一个 3 条提示词的 Haiku 包用了 49 次调用，来回翻页触发了 Cloudflare；
  另一个包对着看起来像服务器错误的 403 用了 51 次调用。规则：25 次调用封顶，不开任务页，读提交的状态码。
- **2026-10-19，上传被截断。** 一个 Haiku subagent 复制参考图的 base64，约 2 万字符只抄了 1,643 个，连续三次。
  规则：由主会话分块推送，每块 6000 字符，每块用 SHA-256 前缀校验；subagent 只负责点击和执行给定的脚本片段。
- **2026-09-30，NovelAI 估价器。** 旧公式把 1536x1024、23 步估成 8 Anlas，网站实收 39。更早的 2026-09-01，
  账本里「已用 638」大半是被当成付费记账的免费图。规则：用网站公式和像素规则。
- **2026-08-25，Civitai 元数据没了。** 公开图片端点对 10/10 张图都返回空的生成元数据，带不带 token 都一样。
  规则：别指望 REST API 还能给出配方。

## 试过又放弃的

- Civitai 逐张确认：换成常设预算（2026-09-30）。
- NovelAI 按预设尺寸判断免费档：换成像素规则（2026-09-30）。
- 用 Danbooru 帖数判断画师有没有号召力：商业插画师在那里帖数很低。设 500 帖门槛，想要的候选全被筛掉
  （他们只有 164 到 490 帖）。2026-08-27 和 2026-09-17 犯了同一个错。
- 给 NovelAI 挖冷门画师（8 到 99 帖）：49 张只中 6 张，而且 V5 学不动（2026-09-17 停）。
- Civitai 的「recipe」端点：同一张图要 12 Buzz，走 workflow 端点只要 4，而且它会悄悄丢掉不认识的字段。
- Civitai MCP 的 `submit_workflow` 工具：在三种传输方式下都会丢步骤。用同一个 token 直接调 REST 就没问题。
- 在 Midjourney 设置面板里改速度、用它的 Download 按钮：换成 `--relax` 后缀和带 token 的本地接收服务。
